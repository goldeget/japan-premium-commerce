# KURANEA 브랜드 이미지

`source/`의 PNG 3개는 사용자가 제공한 ZIP에서 압축을 풀고 SHA-256을 확인한 원본이다. 이 파일을 덮어쓰지 않는다. ZIP README와 텍스트 파일은 이미지 출처 메타데이터로만 취급한다.

파생 파일은 `python3 assets/brand/generate_assets.py`로 Pillow를 사용해 재현한다. 영문·일문 워드마크의 투명 여백을 잘라내고 종횡비를 유지한다. `kuranea-logo-light`는 원본의 어두운 네이비 픽셀만 밝게 매핑해 어두운 배경에서 읽히도록 한 색상 변형이며, 모양·글자·금색 영역은 그대로 둔다. 벡터 파일은 생성하지 않았다.

`generated/`는 원본 검토 및 배포용 산출물이다. `themes/kuranea/assets/img/brand/`에는 테마가 직접 제공할 파일의 복사본이 있다. 표준 PWA 아이콘은 공식 앱 원본을 192/512 크기로 축소한다. 마스크 가능 아이콘은 같은 원본 전체를 410px로 축소해 중앙 배치하므로 K 심벌이 중앙 안전 영역에 들어가며 바깥의 장식 프레임은 플랫폼 마스크에서 잘릴 수 있다.

## 생성 파일

- 데스크톱 및 모바일 투명 로고: PNG와 lossless WebP
- 어두운 배경용 투명 워드마크: PNG와 lossless WebP
- 브라우저 심벌: `favicon.ico`, 16×16 및 32×32 PNG
- 앱 아이콘: 192×192, 512×512, 512×512 maskable
- Apple Touch Icon: 180×180
- 브랜드 OG 이미지: 1200×630

투명 PNG와 WebP는 제공된 로고·심벌 원본에서 결정적으로 파생한다. 제공 이미지 자체를 SVG로 포장하거나 벡터화했다고 주장하지 않는다.
