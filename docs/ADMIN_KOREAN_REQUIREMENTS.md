# KURANEA — MASTER DEVELOPMENT DIRECTIVE
## 필수 개정사항: 관리자 시스템 100% 한국어

### P0 — 절대 변경할 수 없는 언어 정책

KURANEA 프로젝트의 고객용 쇼핑몰과 관리자 시스템은 서로 다른 언어 정책을 사용한다.

**고객용 쇼핑몰**
- 일본어(ja-JP): 기본 언어
- 영어(en): 선택 가능
- 한국어(ko-KR): 선택 가능
- 기본 통화: JPY
- 대상 시장: 일본

**관리자 시스템(Back Office)**
- 기본 언어: 한국어(ko-KR)
- 모든 관리자 및 운영 직원의 기본 인터페이스: 한국어
- 관리자 업무 화면: 한국어 100%
- 관리자에게 제공하는 사용 설명서: 한국어
- 관리자 운영 보고서 및 알림: 한국어

이 요구사항은 UI/UX 디자인, 쇼핑몰 기능 구현, 관리자 기능 확장과 동일하게 필수 인수 조건에 포함한다.

고객용 쇼핑몰의 기본 언어를 일본어로 유지하면서 관리자 페이지는 한국어로 작동하도록 독립적으로 설정하라.

PrestaShop의 전역 기본 언어를 한국어로 변경하여 고객용 일본어 쇼핑몰의 기본 언어까지 변경하는 방식은 금지한다.

# 2. PrestaShop 한국어 관리자 구현

PrestaShop 9 계열의 실제 한국어 번역 지원 범위를 조사한다.

다음 순서로 진행한다.

1. 공식 한국어 언어팩 제공 여부 확인
2. PrestaShop Back Office 한국어 번역 적용
3. 관리자 직원 계정의 언어를 한국어로 설정
4. 기존 코어 관리자 화면의 미번역 문구 조사
5. 공식 번역 시스템을 이용해 부족한 한국어 번역 보완
6. 커스텀 모듈의 모든 한국어 번역 구현
7. 관리자 전체 화면의 미번역 영어·프랑스어 문자열 검출
8. 실제 브라우저에서 한국어 관리자 화면 검증

가능하면 PrestaShop의 표준 Translation Domain과 XLF 번역 구조를 활용한다.

PrestaShop 원본 코어를 무분별하게 수정하지 않는다.

코어 업데이트 이후에도 한국어 번역이 유지되는 구조를 설계한다.

번역이 없는 화면을 영어로 방치하지 마라.

번역 누락은 별도의 QA 결함으로 기록하고 해결한다.

# 3. 한국어 관리자 UI/UX 품질

관리자 페이지도 고객 쇼핑몰에 준하는 디자인 품질을 갖춰야 한다.

기존 PrestaShop 관리자 기능은 유지하면서, 새 커스텀 모듈의 인터페이스를 일관된 디자인 시스템으로 구현한다.

운영자는 개발자가 아닌 일반 한국어 사용자라는 전제로 설계한다.

### 관리자 디자인 원칙

- 직관적인 한국어 메뉴
- 간결한 대시보드
- 가독성 높은 표와 검색 필터
- 명확한 상태 표시
- 업무 처리 버튼의 일관된 위치
- PC 화면 중심의 효율적인 작업 구조
- 태블릿·모바일 반응형 지원
- 불필요한 입력 단계 최소화
- 실수 방지를 위한 확인 창
- 중요한 금전 관련 변경은 권한 검증
- 사용자 친화적인 오류 메시지

필요한 거래 기록은 시스템이 자동 보존하되, 평소 관리자 화면에 불필요한 기술 로그를 과도하게 노출하지 않는다.

### 실제 한국어 화면 예시

관리자 메뉴:

- 대시보드
- 상품 관리
- 상품 수집
- 주문 관리
- 입금 관리
- 고객 관리
- 고객 상담
- 지갑 관리
- 수익 정산
- 출금 관리
- 배송 관리
- 콘텐츠 관리
- 언어 관리
- 직원 및 권한
- 회사 정보
- 시스템 설정

고객 지갑 관리 화면의 예시 버튼:

- 잔액 지급
- 잔액 차감
- 충전 내역
- 거래 내역
- 고객 상세정보

출금 관리 화면의 예시:

- 출금 신청
- 검토 중
- 승인
- 거절
- 송금 확인 대기
- 송금 완료

운영자는 화면을 보는 즉시 각 기능을 이해할 수 있어야 한다.

# 4. 고객용 다국어 상품관리와의 분리

관리자는 한국어 화면에서 일본어·영어·한국어 상품정보를 편집할 수 있어야 한다.

예시:

관리자 메뉴: 상품 관리

상품 편집 화면:

- 상품명
  - 일본어
  - 영어
  - 한국어
- 상품 설명
  - 일본어
  - 영어
  - 한국어
- 판매가격
- 상품 옵션
- 재고
- 이미지
- 공개 상태

관리자가 언어별 상품정보를 편집하더라도 관리자 시스템의 메뉴와 버튼은 계속 한국어로 표시한다.

고객용 언어 설정과 관리자 언어 설정이 서로 영향을 주지 않도록 한다.

3. 상품 등록

# 7. 최종 인수 조건

고객용 쇼핑몰은 일본어를 기본으로 영어·한국어까지 지원해야 한다.

관리자 시스템은 한국어로 운영할 수 있어야 한다.

기존 PrestaShop Back Office, 커스텀 관리자 모듈, 주문·입금·고객·상품·상담·지갑·출금 관련 운영 화면 전체가 대상이다.

관리자의 상품정보 입력 데이터에 일본어·영어가 포함되는 것은 허용하지만 관리자 인터페이스 자체에 번역 누락이 남아서는 안 된다.

기본 화면뿐 아니라 실제 업무 처리 과정의 알림·오류·확인 메시지까지 검증한다.

**최종 원칙: 고객용 쇼핑몰은 일본어 중심 3개 언어, 관리자 시스템은 한국어 100%다.**

이 정책을 `AGENTS.md`, `docs/PROJECT_REQUIREMENTS.md`, `docs/DESIGN_SYSTEM.md`, `docs/TEST_RESULTS.md`에 반영하고 이후 모든 개발 단계의 필수 조건으로 유지하라.

GitHub 원격 저장 및 복구 테스트를 먼저 통과한 뒤 이 요구사항을 적용하여 개발을 진행하라.
