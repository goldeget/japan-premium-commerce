- 검토 대상 저장소/브랜치: `goldeget/japan-premium-commerce`, `work`.
- 현재 work HEAD 및 확인된 origin/work SHA는 d49fa7d2e5b7714fee8f31bdd1558f54bdb2a6d7이다. main은 ee02a3657448d563508687614a246e05ac61eecd로 유지한다. 이 변경에는 동일 imported draft의 편집 저장·재조회·재수집 browser 검증이 추가됐다.

- 과거 #40240641970의 storefront locale/admin recovery 실패는 이후 #40247656819와 #40272141646의 새 locale·reset 검증 근거로 갱신됐다. 현재 import 기능은 커밋된 코드이며 e1cd6d0의 격리 성공 근거와 d49fa7d의 진행 중 검증을 구분한다.
